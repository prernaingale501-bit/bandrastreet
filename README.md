# Bandra Street — Complete React + TypeScript + Tailwind CSS Project

## Live Site

[Open Bandra Street](https://prernaingale501-bit.github.io/bandrastreet/)

The site deploys to GitHub Pages from the `main` branch.

## Local Setup
```bash
npm install
npm run dev
```

## Included Files
- `index.html`, `vite.config.ts`, `tsconfig.json`, `tailwind.config.js`, `postcss.config.js`
- `src/index.css` (Tailwind directives + editorial fonts & animations)
- `src/main.tsx` & `src/App.tsx` (Portal switcher between Storefront, Vendor Portal & Admin Dashboard)
- `src/storefront/BandraStreetStorefront.tsx`
- `src/vendor/VendorDashboard.tsx`
- `src/admin/AdminDashboard.tsx`
- `supabase/migrations/001_bandra_street_rls.sql`
